Roles y permisos

Cada usuario puede tener varios roles; sus permisos se combinan.

+ Crear rol
ADMIN Gestionar usuarios, roles y catálogos; administrar productos; registrar entradas y ventas; consultar el inventario.
VENDEDOR Registrar entradas y ventas, consultar productos y existencias. No puede administrar usuarios, roles ni catálogos.
USER Consultar el catálogo público. No puede gestionar el inventario ni registrar movimientos.
